# Security Policy

## Scope & Synthetic Telemetry Guarantee
This repository contains zero-dependency Python 3 (`stdlib`-only) telemetry, PCI-DSS v4.0 / GLBA sanitization, and bounded auto-remediation pipelines. All cardholder data (PAN, CVV, Routing/Account numbers) used in tests and fault-injection drills is synthetic.

## Reporting a Vulnerability
Do not open public issues for security vulnerabilities. Report privately via GitHub Security Advisories for `rfeatherstone-remote-engineer/fintech-s3-telemetry-lab`.
