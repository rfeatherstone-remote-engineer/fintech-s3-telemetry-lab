# RB-001: Cardholder Data Leak (PCI-LEAK-001)
- **Trigger:** Luhn-valid PAN (`PCI-DSS 3.4`), CVV (`PCI-DSS 3.3`), or ABA Routing (`GLBA`) detected in telemetry.
- **Automated Action:** In-memory redaction/purge + `0600` quarantine artifact + blameless RCA.
- **Escalation:** Rotate upstream application logging tokens if `CVV` purge fires.
